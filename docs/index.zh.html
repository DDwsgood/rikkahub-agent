功能

一个智能体该有的，都有。

十二大能力板块，每一项默认关闭，等你亲手打开。

掌控你的手机

点击、滑动、滚动、输入、打开应用、手电筒、亮度、音量、通知、震动、分享。还能读取电量、WiFi、信号、位置、传感器、联系人和短信。80+ 工具，全部内置在 Android 里，无需安装额外应用。

应用内浏览器

一个 AI 全程驱动的真实 WebView。它在后台无头运行——打开网址、点掉 cookie 弹窗、填写表单、滚动页面，然后把内容读给你听。内置正文提取和操作后差异对比，token 开销压到最低。

工作流

Tasker 级别的自动化，但规则由 AI 用自然语言写成。19 种触发器（WiFi、蓝牙、耳机、地理围栏、应用启动、通知、屏幕、充电、时间等）加 14 种条件（电量、日落、前台应用、星期几）。接收器按需注册，省电。

定时任务

"每周一早上 8 点"、"每两小时"、"下周五下午 3 点"。任务能扛住重启和省电模式。你可以让 AI 在触发时现场决策，也可以预置固定动作、不消耗任何 token。

口袋里的 SSH

服务器信息保存一次，AI 随时可以 SSH 上去。跑命令、传文件、拉备份、看日志。支持密钥认证和主机保存，首次连接和危险命令都有审批拦截。

Telegram 机器人

在任何地方和你的助手对话。用 @BotFather 建一个私有 bot，像跟联系人聊天一样使用它。语音、照片、PDF 都能收发，语音由本地 whisper.cpp 转写。审批按钮内嵌在消息里，仅限白名单用户。

查找与管理文件

内置文件管理器，AI 可以直接操作。"找出我手机里所有提到'发票'的 PDF"一句话就能搞定。读取、保存、复制、移动、重命名、删除。系统目录一律禁止访问，你开口也没用。

音乐与媒体

走 Android 标准媒体控制（锁屏封面、耳机按键都能用）。暂停、继续、开会时调小音量、之后再调回来。即使应用被强杀，AI 也能从同一首歌、同一个进度继续。

Skills

往应用里丢一个 Markdown skill 文件，AI 就多了一套可以照着执行的 playbook。JavaScript skill 在隐藏的 WebView 里运行，结果在应用内浏览器中打开。内置精选目录附带二维码生成器、维基百科查询、交互式地图等。

子智能体

长任务可以由主助手派发专注的子智能体，在干净的侧上下文里运行，还能换用更便宜的模型。多个可以并行：一个查资料，另一个更新你的服务器。/stop 一次取消所有活跃子任务。

Doctor 体检

内置健康检查。设置里的 Doctor 会做一轮全面体检：权限、后台服务、数据库完整性、网络、Termux。逐项一键修复——授予缺失权限、重启服务、重建聊天搜索索引。没有启用对应工具的权限项会自动跳过。

三层安全防护

按助手开关——每个工具默认关闭。逐次审批——允许一次、本对话内允许、总是允许，或拒绝。HARDLINE 底线——清空数据、fork 炸弹以及绕过规则的 shell 花招一律无条件拦截。

快速上手

一分钟内跑起来。

聊天本身零配置。工具和机器人按需开启。

1

安装。从 Releases 下载最新的 *-universal-debug.apk，允许安装未知来源应用，然后打开。

2

添加 LLM 提供商。设置 → 提供商 → 任选一个 → 粘贴 API key。Pixel 8/9/10 用户可以打开内置的 AICore 卡片，直接使用端侧 Gemini Nano。

3

开启你要的功能。设置 → 助手 → 点进你的助手 → 本地工具 → 打开需要的分类。

4

（可选）Telegram 机器人。从 @BotFather 拿 token，从 @userinfobot 拿你的数字 ID，然后在聊天里说："帮我配置 Telegram 机器人。Token 是 …，我的用户 ID 是 …，设为默认聊天并启用。"

5

直接说事儿。如果你什么都没开，应用的行为和原版 RikkaHub 一模一样。

常见问题

你可能想问

这里没有覆盖到的问题，欢迎在 GitHub 上开 issue。

需要 root 吗？
不需要。RikkaHub Agent 只使用标准 Android 权限和无障碍服务 API，不需要 root、Magisk 或第三方 ROM。少数高级工具（通知监听、屏幕自动化）需要在设置里一次性点按授权，其余都是运行时权限。
我的数据会被发到别处吗？
只会发给你自己选的 LLM 提供商。如果你在 Pixel 8/9/10 上选择 AICore，推理完全在本地进行，任何内容都不会离开手机。密码和 API key 永远不会写进日志文件。云端备份会跳过已保存的服务器凭据和 Telegram bot token。
支持哪些 LLM 提供商？
OpenAI、Google、Anthropic、Ollama，以及任何 OpenAI 兼容端点（Groq、Mistral、OpenRouter、vLLM、llama.cpp、LM Studio 等）。另外 Pixel 8/9/10+ 可以用 AICore 跑端侧 Gemini Nano。
危险工具是怎么处理的？
三层防护，最严的在最后。(1) 每个工具分类默认关闭，你按助手逐个开启。(2) 有实际后果的工具（SSH 命令、删除文件、启动应用、发送消息）执行前会询问你，可选允许一次 / 本对话 / 总是允许 / 拒绝。(3) 一小份 HARDLINE 清单（清空数据、重启、fork 炸弹、破坏系统文件、以及绕过规则的 shell 花招）无条件拦截——就算你明确要求 AI 做，它也不会执行。
定时任务能扛住重启和省电模式吗？
能。任务持久化保存，重启后自动恢复；定时服务以前台服务方式运行，Doze 和省电模式不会杀掉它。每个任务都会保存 prompt、助手和触发配置，多次执行行为可复现。
和原版 RikkaHub 有什么区别？
上游 RikkaHub 是一个漂亮的原生 LLM 聊天客户端。这个 fork 完整保留了它的 UI，并加上智能体层：80+ 设备工具、AI 驱动的应用内浏览器、自然语言工作流、定时任务、子智能体、skill 系统（Markdown + JavaScript）、SSH、Telegram 机器人、音乐与媒体控制、通知监听、文件管理器、屏幕自动化、Doctor 诊断菜单，以及三层审批机制。如果你一个新功能都不开，它的行为就和原版 RikkaHub 完全一样。
和上游 RikkaHub 团队有关系吗？
没有。这是一个独立的 fork。聊天客户端、提供商抽象和 UI 设计的所有功劳属于 Re-ovo 和上游贡献者。智能体层的问题请提到这个仓库，不要打扰上游。
Releases 里的几个 APK 分别是什么？
每个版本提供三个 debug 签名的 APK：*-arm64-debug.apk 适合几乎所有现代手机，*-x86_64-debug.apk 给模拟器和 x86 Chromebook，不知道该选哪个就用 *-universal-debug.apk（两个都打进去，体积更大）。版本标签格式为 vX.Y.Z-agent.N，其中 vX.Y.Z 是上游 RikkaHub 版本号，N 是在其之上的智能体修订号。由于 APK 不是 Play 商店签名，Google Play Protect 可能提示"此应用可能有害"，点"仍然安装"即可，也可以临时关闭 Play Protect 的扫描再安装。
